# Idrees Travels

Website for **Idrees Travels**, an air ticket and Umrah package agency in Bara Bazar, District Khyber.

*Connecting you to the world.*

## Pages

| File | Page |
| --- | --- |
| `index.html` | Home |
| `about.html` | About Us |
| `services.html` | Our Services (air tickets and Umrah packages) |
| `contact.html` | Contact Us (enquiry form that opens WhatsApp, plus a map) |

## Structure

```
assets/
  css/style.css   brand colours and all styles
  js/main.js      mobile menu, scroll effects, WhatsApp enquiry form
  img/            logo, light logo for dark backgrounds, favicons
  fonts/          Montserrat (same typeface as the logo)
```

Plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser, or host on GitHub Pages.

## Editing common details

- **Phone / WhatsApp:** search for `9409133` across the HTML files, and update `WHATSAPP_NUMBER` in `assets/js/main.js`.
- **Umrah packages:** edit the package cards in `index.html` and `services.html` (search for `Price on request`).
- **Colours:** change the variables at the top of `assets/css/style.css`.
